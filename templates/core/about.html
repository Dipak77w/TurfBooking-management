Academic Mini-Project

Turf Booking & Management Platform

Developed as a professional full-stack web application designed to solve real-world sports facility scheduling challenges across Chhatrapati Sambhajinagar, Maharashtra.

Key Technical Highlights

  • Two Separate Login Architectures: Isolated Customer (Player) and Admin (Turf Owner) role-based authentication flows.
  • Atomic Concurrency Locks: Uses Django database transactions with select_for_update checks to physically prevent simultaneous double-bookings.
  • Manual UPI QR Verification Engine: Turf owners set their custom UPI ID and QR code; customers submit real transaction UTR proofs for transparent verification.
  • 30-Minute Cancellation Enforcement: Automatic policy locking bookings inside a 30-minute window before match kickoff while allowing effortless cancellation outside it.
Technology Stack
Backend: Python 3.14 & Django 6.1
Database: SQLite3
Frontend: HTML5, CSS3, JavaScript
UI Framework: Bootstrap 5.3
Icons: Bootstrap Icons
Analytics: Chart.js
Location Focus: Chhatrapati Sambhajinagar, MH
Demo Listings: All 3 turfs (City Sports Arena, Champion Box Cricket Turf, Greenfield Football Turf) are demonstration listings created for this mini-project.
